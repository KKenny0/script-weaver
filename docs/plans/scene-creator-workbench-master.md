# Script Weaver 创作者工作台主计划

日期：2026-09-05。状态：计划获准执行；阶段 1 原型待用户确认，阶段 2–5 尚未按本计划实施。

本文件承接用户确认的完整计划。既有能力与历史验收见 [创作者工作台实施记录](creator-workbench-implementation.md)；旧记录中的通过不等于本计划已交付。

## 1. 产品目标与范围

以场次为核心，服务独立短剧、漫剧创作者。从想法或材料出发，在同一上下文完成故事、剧本、视觉选择、分镜预演，交付版本化生产包。优先单人、本地使用；Codex 使用外部 CLI + Skills，不内嵌运行时。

先确认可点击原型，再进入生产 UI。人工编辑、保存、比较和导出不依赖 Codex 或媒体供应商。没有实际运行的服务必须单独标记。

不建设多人协作、云同步、无限画布、自动跨阶段执行、完整剪辑、配音、字幕、混音与发行，不扩张供应商数量。

成功标准：完成一场戏的反复修订，变成可预演镜头，复用设定进入第二集，并导出与已采用版本一致的资料。

## 2. 产品结构与交互契约

### 导航

外层作品库提供创作中/已归档、搜索、新建、归档恢复及每部作品上次位置。进入作品后采用作品 → 分集 → 场次，顶部名称可快速切换作品，左上返回作品库。作品草稿、候选、设定和工作位置隔离。已有作品恢复上次位置；新作品按输入进入对应起点。剧本、分镜、预演保留当前集、场、镜头。人物/地点/道具默认侧栏打开，全库用于跨集管理。原始材料、开发稿和审查按归属组织，取消全项目文档标签与分集导航的重复。

历史、执行详情、底层变更按需展开。宽屏三栏，窄屏右侧抽屉。保存失败保留当前内容并提示离开风险。Light/Dark 延续温暖克制的编辑桌面，正文优先，减少工程术语和常驻状态。

### 四种入口与开发

- 想法：故事与分集，支持人工或 Codex 发展。
- 长材料：保留原文，先分析再开发，保留来源映射。
- 单集剧本：采用或修订；正式分镜前处理格式问题。
- 多集整稿：核对边界与来源后进入各集。

梗概、创作承诺、人物冲突和分集卡片仍属同一开发稿，不新增审批对象。支持新增与修改卡片；来源绑定卡片只读并可定位原文。首版不增加集数重排、删除或来源片段重划。格式错误不得丢弃或自动改写输入。

### 场次写作

默认场次目录与当前场正文；支持整集阅读、高级 Markdown。内外景/地点/时间生成标题，正文轻量编辑。所有视图编辑同一 Markdown 草稿，复用保存协调器。支持追加场次，不提供场次拖拽重排/删除。无法可靠识别的正文退到完整编辑并定位问题。

草稿可以未投影，进入分镜前说明所依据的已采用版本。当前场或选区直接发起修订。

### AI 候选

选择内容 → 描述要求与保留事项 → 外部执行 → 比较 → 保留候选 → 采用。

任务交接包括任务 ID、工作目录、claim/context/submit 要求，不包括 token。未领取、处理中、失败、返回候选使用真实状态，不虚构在线或百分比。项目事件自动回流，断线可重连和手动刷新。

默认突出变更段落，可核对全文。两道决定保留，放在同一面板。退回填写反馈，新尝试新建任务。采用并继续编辑需事务校验；并发新稿存在时拒绝覆盖，保留两者。

主界面以“创作助手”呈现当前内容的要求、反馈和候选；执行信息按需展开。外部 Codex 尚未领取时仍须提供明确的一次性交接入口，不能仅靠隐藏任务详情暗示已自动执行。原型可模拟返回，但必须标明模拟。

### 视觉、镜头和预演

侧栏展示正式图、简短设定、候选和引用；提示词、哈希、来源放详情。比较同批三图，父候选局部修改，采用成为正式参考。不支持参考编辑的供应商必须明确说明，不以纯文本生成冒充局部编辑。

正式无图展示空状态；测试生成器和示例素材不作为普通创作默认。复用真实图片生成与 Agent 导入，不另建上传/供应商体系。

剧本到分镜增加明确过渡：当前场正文 → 描述拍法与节奏 → 确认所依据的剧本 → 比较镜头方案 → 保留候选 → 采用为镜头表 → 准备静帧 → 预演。方案说明每个镜头的戏剧目的、画面和时长；候选不提前替换已采用镜头，文字方案不冒充已有画面。

当前场建立镜头，编辑顺序、时长、画面意图、绑定和提示词。预演按顺序播放已采用静帧，支持暂停、跳转和对白提示；缺图保留时长并显示占位。静帧不称为生成视频。H3 实际可用才出现生成入口，资源消耗由创作者确认。

## 3. 实现边界与接口

SQLite 版本化 Markdown 仍是事实源。accepted screenplay 单向产生投影。Agent 不能接受文档、覆盖草稿或确认生成。历史不可变；不新增 ORM、Redux、通用队列或依赖图。

草稿场次通过文档、草稿 revision、正文范围定位；正式场次通过投影版本及场次/分段关联定位。无法关联时重新选择，不按编号自动绑定。采用新版保留整集旧投影失效规则，提前说明影响；不承诺场级精准失效，不自动搬移旧镜头。旧镜头只读保留。

最小接口变更：

1. 文档决定增加可选“采用并继续编辑”和预期草稿 revision；采用/投影/草稿更新同一事务，旧请求不变。
2. 文档或场次查询增加草稿范围、格式问题和正式关联，复用后端解析规则，不新增场次草稿表。
3. 保留 Task/ChangeSet/媒体/事件接口；局部修订提交完整候选并校验范围外正文。
4. 生产包提供 creator 可下载的归档，复用现有记录和不可变目录，前端不拼装事实。
5. 镜头排序若现有更新不能保证原子性，增加分段级重排，校验归属、完整集合和 revision。

接口向后兼容。默认不新增表。工作位置仅为浏览器可丢弃偏好。

生产包包括：已采用开发稿/剧本、镜头表/时长/提示词/引用版本、正式参考与镜头图片/视频、版本清单及 missing/failed/stale/excluded。归档相对路径，无 token、私有绝对路径、未采用候选或权重。允许不完整包，无视频不阻断资料交付，但不得声称完整成片。单快照生成，失败清理临时文件，不覆盖旧包。

## 4. 阶段与门槛

| 阶段 | 交付 | 完成门槛 |
|---|---|---|
| 1 | 可点击原型：场次、AI、视觉、预演、交付，Light/Dark 与异常 | 用户确认原型后进入生产 UI |
| 2 | 场次写作、外部交接、回流、候选与续写 | 真实 Codex 局部修订；刷新、退回、并发恢复 |
| 3 | 视觉比较/编辑、镜头与静帧预演 | 真实图片循环；一场三个镜头；返回原处修改 |
| 4 | 跨集设定复用与影响复核 | 第二集共用身份；不自动改写下游；旧投影可读 |
| 5 | 生产包下载与缺项修复 | 实际资料独立打开核对；旧包不变 |

阶段独立可用。生产改造预计超过八个文件，按行为分批，不全量重写。

## 5. 验证与回退

自动回归沿用 pytest、保存竞争、候选审批、多集、视觉、视频与 production build。新增检查覆盖：Markdown 往返（emoji/空行/损坏标题/不完整稿）；选区越界；三道 revision 闸门；采用/投影/续写原子性；跨项目/分集/投影定位；父候选/参考保持；镜头原子排序与预演时长；归档版本与哈希、秘密/路径泄漏。

真实验收在隔离数据与生产构建中完成：创建两集开发稿 → 写一场并刷新 → 真实 Codex 退回一次再采用 → 真实图片修改与失败恢复 → 三镜头预演 → 第二集复用和替换参考 → 在工作台外核对生产包。

浏览器覆盖 1440×900、1024×700、Light/Dark 和键盘操作。记录是否需搬运上下文、是否理解生效版本、能否从预演返回、再次进入是否可继续。H3 没有真实环境时标未验证，不能以测试服务器代替。

生产阶段再同步 ADR 和 README 定位。原型阶段不提前宣称生产架构已变更。回退保留全部 Markdown、版本和媒体，旧接口行为保持，不删除用户数据或改动。
