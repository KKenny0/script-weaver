- 本原型为每部作品分别保存任务、草稿和位置；《未通过的好友申请》包含一组参考及第一集第二场的三个镜头，其余作品从故事写作开始。不是生产数据模型。任意输入对应确定性示例候选，不代表真实 AI 对意图的理解。
- 两集切换共享示例道具版本；采用新剧本后旧镜头只读，不演示自动迁移或场级精准更新。

- 下载只提供明确标记 `prototype: true` 的 JSON 清单，不是 ZIP 生产包。真实导出/参考绑定/供应商检测留给生产阶段。

## 建议审阅路径

1. 从作品库打开《未通过的好友申请》，选择第一集第二场编辑正文；保存并刷新，检查场次目录、整集阅读与 Markdown。
2. 点“一起打磨这一场”或选中文字后发起，填写要求 → 自动演示返回 → 比较 → 留下这版 → 采用这版，继续写。执行与来源折叠展示 Codex 交接说明。
3. 接受前可填写退回反馈再试；采用后正文直接更新，旧分镜标记只读。
4. 打开“本场设定 → 指甲锉”，比较 A/B/C，模拟局部修改，采用新参考并查看两集影响。
5. 切换预演，跳到镜头 02，播放/暂停，回到对应镜头；缺图镜头保留时长。重置示例后可调整镜头顺序、时长、画面意图及选用示例静帧。
6. 从引用跳到第二集，确认仍使用同一参考版本。
7. 进入交付，查看正文/镜头/参考/缺图定位，下载示例清单。
8. 左侧“原型演示设置”可演示保存失败、采用冲突、图片失败、通知断线与重置。顶部切换 Light/Dark。
